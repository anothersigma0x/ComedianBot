# Comedian Bot

Un bot interactivo de chistes en HTML, CSS y JavaScript. Muestra chistes en un chat simple con avatares y delays para simular una conversación.

## Cómo usar
1. Abre `index.html` en tu navegador.
2. Haz clic en "Tell me a joke!" para que el bot cuente un chiste.
3. El chat se actualiza automáticamente con mensajes del usuario y del bot.

## Archivos
- `index.html`: Estructura principal.
- `style.css`: Estilos para el chat.
- `script.js`: Lógica para los mensajes y chistes.

## Requisitos
- Ninguno (solo un navegador moderno).
